“Nothing found” is not “fraud”. Plenty of excellent operators have no web presence, and a verification tool that treats absence as guilt quietly filters for people who post a lot. The four verdicts are worded to keep that distinction in front of whoever is reading.

Why generation matters here. These exhibits were previously rebuilt by hand each reporting period from spreadsheet exports. Every hand-rebuild is a chance for the report and the underlying data to drift apart, and the whole point of a compliance document is that it does not. Generating them from the same source the dashboard reads makes drift structurally impossible.
